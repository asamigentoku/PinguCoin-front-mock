# PinguCoin client-web-mock

バックエンド、Clerk、外部ストレージ、外部翻訳APIなしで動くフロントエンド確認用アプリです。

```powershell
cd apps/client-web-mock
npm install
npm run dev
```

ブラウザで <http://localhost:3002> を開きます。ログイン画面に表示される用意済みアカウントを選ぶと、商品閲覧、カート購入、ポイント追加、購入ファイルのダウンロード、出品・編集・削除を確認できます。メールアドレスやパスワードの入力、アカウント作成は不要です。

ログイン状態はCookieへ7日間保存されますが、外部の認証サービスへ情報は送信しません。

データはNext.jsプロセスのメモリに保存されるため、開発サーバーを再起動すると初期状態に戻ります。決済、アップロード、ダウンロード、翻訳は画面確認用の疑似動作であり、外部サービスへは送信しません。
